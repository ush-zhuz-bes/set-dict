1Қайталау 0–5 минут

Қысқа сұрақтарға жауап беріңіз де, «Тексеру» батырмасын басыңыз. Дұрыс жауап тек тексергеннен кейін көрсетіледі. Теория бөлімінің барлығы — 15 минут, қалған 35 минут практикаға арналған.

Жиын (set) деген не?

Дұрыс жауап: Қайталанбайтын (бірегей) элементтер жиынтығы

Жиын тек бірегей элементтерді сақтайды. Индекс бойынша қатынау жоқ, реті кепілдік берілмейді.

Бос жиынды қалай дұрыс жасауға болады?

Дұрыс жауап: set()

{} — бос сөздік (dict). Бос жиын тек set() арқылы жасалады.

student = {'name': 'Asan', 'age': 20} жазбасында 'age' пен 20 қалай аталады?

Дұрыс жауап: 'age' — кілт, 20 — мән

Сөздікте жазба «кілт: мән» түрінде. Кілт арқылы мәнді табамыз. Кілттер бірегей болады.

Сөздікте 'phone' кілті жоқ. student.get('phone') пен student['phone'] не береді?

Дұрыс жауап: get() — None (қате жоқ), [] — KeyError

get() кілт жоқ болса None (немесе өзіңіз берген мән) қайтарады. Ал dict[key] — KeyError көтереді.

Негізгі код

Кодты оқып, нәтижесін алдымен болжаңыз, содан кейін өз компьютеріңізде орындап салыстырыңыз.

Есте сақтаңыз: {} — бос сөздік; бос жиын тек set() арқылы жасалады.

2Жиындар 5–10 минут

Жиын (set) — бірегей, қайталанбайтын элементтер жиынтығы. Индексі жоқ, элементтерінің реті кепілдік берілмейді.

Құру және тексеру

set()бос жиын; set(тізім) — тізімнен жиын
{1, 2, 3}элементтерді тікелей жазу
len(s)элемент саны
x in sx жиында бар ма? (True/False)

Жиын элементі өзгермейтін (hashable) болуы керек: сан, мәтін, кортеж болады; тізім, жиын, сөздік болмайды.

Өзгерту

s.add(x)элемент қосады
s.remove(x)өшіреді; x жоқ болса — KeyError
s.discard(x)өшіреді; x жоқ болса да қате жоқ

Жиын амалдары

АмалОператорӘдісМағынасы
Бірігуa | ba.union(b)екеуінің барлық элементі
Қиылысуa & ba.intersection(b)екеуінде де бар элементтер
Айырымa - ba.difference(b)a-да бар, b-да жоқ
Симметриялық айырымa ^ ba.symmetric_difference(b)тек біреуінде бар
Реті тұрақты емес. Жиынды print() жасағанда элементтердің реті әртүрлі болуы мүмкін. Сондықтан мысалдарда нәтижені салыстыру үшін sorted() қолданылады (ол тізім қайтарады).

remove() және discard()

Егер remove() жоқ элементті өшіруге тырысса — KeyError шығады. discard() болса, қате бермейді. Элемент міндетті түрде бар екеніне сенімді болсаңыз remove(), сенімсіз болсаңыз discard() қолданыңыз.

frozenset

frozenset — өзгермейтін жиын. Ол set сияқты бірегей элементтерден тұрады және одан |, &, - амалдарын орындауға болады, бірақ жасалғаннан кейін add(), remove(), discard() арқылы өзгертуге болмайды. Өзгермейтіндіктен оны басқа жиынның элементі немесе сөздіктің кілті ретінде қолдануға болады. Жасалуы: frozenset([1, 2, 3]).

Дереккөз: оқу-әдістемелік кешен, №8 дәріс «Жиындар», PDF 67–74-б. Мысалдар Python 3 синтаксисімен жазылған.

3Сөздіктер 10–15 минут

Сөздік (dict) мәліметті кілт: мән жұптары түрінде сақтайды. Мәнге индекс емес, кілт арқылы қатынаймыз.

Негізгі ережелер

  • Жазылуы: {кілт: мән}, бос сөздік — {} немесе dict().
  • Кілттер бірегей: бір кілт қайталанса, соңғы мән қалады.
  • Кілт өзгермейтін тип болуы керек (мәтін, сан, кортеж). Мән кез келген тип бола алады.
  • Қазіргі Python 3 сөздігі элементтерді енгізілген ретімен сақтайды (Python 3.7-ден бастап тілдің кепілдігі).

Қатынау және өзгерту

d[key]мәнді оқу; кілт жоқ болса — KeyError
d.get(key, x)кілт жоқ болса, қате емес, x (немесе None)
d[key] = vкілт бар болса — мәнді өзгертеді, жоқ болса — қосады
key in dкілттің барын тексереді

Әдістер

d.keys()кілттерd.values()мәндер
d.items()(кілт, мән) жұптарыd.update(other)басқа сөздіктің жазбаларын қосу/жаңарту
dict.fromkeys(keys, v)кілттер тізімінен бірдей мәнді сөздікdict(zip(keys, vals))екі тізімнен сөздік
Сөздіктер тізімі — кестеге ұқсас деректерді сақтаудың ыңғайлы жолы: әр жол бір сөздік, барлығы бір list ішінде. Зертханалық жұмыстарда дәл осындай деректер қолданылады.

Дереккөз: оқу-әдістемелік кешен, №9 дәріс «Сөздіктер түсінігі және құру принциптері», PDF 74–80-б. Мысалдар Python 3 синтаксисімен жазылған.

4Практикалық тапсырмалар 15–50 минут

Барлық студент бірдей 8 шағын тапсырманы орындайды (4 жиын, 4 сөздік), әрқайсысына шамамен 4 минут. Алдымен өзіңіз шешіп көріңіз, қиындық болса ғана кеңесті ашыңыз. Шешімді өз компьютеріңіздегі Python ортасында (IDLE / VS Code) орындап тексеріңіз.

Бұл тапсырмалар — дәріс мысалдарына сүйенген жаттығулар. Олар зертханалық жұмыс жинағындағы нөмірлі есептермен байланысты емес.

1-тапсырма. Бірегей сандар

Тізімдегі бірегей сандарды өсу ретімен шығарыңыз.

Кіріс деректері 
numbers = [4, 6, 4, 8, 6, 9]

Алдымен тізімді set() арқылы жиынға айналдырыңыз — қайталанғандар жойылады. Содан кейін sorted() қолданып, өсу ретімен шығарыңыз.

2-тапсырма. Қиылысу және айырым

A және B жиындары берілген. Олардың қиылысуын және A − B айырымын табыңыз (екеуін де sorted() арқылы шығарыңыз).

Кіріс деректері 
A = {2, 4, 6, 8}
B = {4, 7, 8}

Қиылысу үшін & (немесе intersection()), айырым үшін - (немесе difference()) қолданыңыз. Нәтижені sorted() ішіне салыңыз.

3-тапсырма. Элемент қосу және өшіру

s жиынына 9 санын қосыңыз, 3 санын өшіріңіз, содан кейін жиында жоқ 100 санын discard() арқылы өшіріп көріңіз (қате шықпауы керек). Жиынды өсу ретімен және элемент санын шығарыңыз.

Кіріс деректері 
s = {1, 3, 5, 7}

add() — қосады, discard() — өшіреді (жоқ болса да қате бермейді). Элемент санын len() береді.

4-тапсырма. Екі топтың аттары

Екі топтың студент аттары берілген. Екі топта да бар аттарды және тек біреуінде ғана бар аттарды өсу ретімен шығарыңыз.

Кіріс деректері 
group_a = {'Aru', 'Dina', 'Eldos', 'Asan'}
group_b = {'Dina', 'Asan', 'Nurlan'}

«Екеуінде де бар» — қиылысу (&), «тек біреуінде» — симметриялық айырым (^). Екеуін де sorted() ішіне салыңыз.

5-тапсырма. Сөздікті өзгерту

score мәнін 85-ке жаңартыңыз, dept кілтін қосыңыз (мәнін өзіңіз таңдаңыз, мысалы 'IT'), содан кейін name мен score мәндерін шығарыңыз.

Кіріс деректері 
student = {'name': 'Dina', 'score': 75}

Бар кілттің мәнін student['score'] = ... арқылы өзгертесіз; жаңа кілт те дәл осылай қосылады. Мәндерді student['name'] түрінде оқыңыз.

6-тапсырма. get() және items()

prices сөздігінен «нан» бағасын [] арқылы шығарыңыз; «шай» кілті жоқ, оның бағасын get() арқылы қате шығармай 0 деп шығарыңыз; содан кейін барлық тауар мен бағасын жолма-жол шығарыңыз.

Кіріс деректері 
prices = {'алма': 450, 'нан': 120, 'сүт': 300}

Кілт бар болса prices['нан'] жұмыс істейді. Жоқ кілт үшін prices.get('шай', 0). Жұптарды for key, value in prices.items(): арқылы алыңыз.

7-тапсырма. zip() және update()

fields және values тізімдерінен zip() арқылы сөздік жасаңыз. Содан кейін update() арқылы age мәнін 22-ге өзгертіп, group кілтін ('IS-31') қосыңыз және сөздікті шығарыңыз.

Кіріс деректері 
fields = ['name', 'age']
values = ['Aru', 21]

dict(zip(fields, values)) сөздік жасайды. update() ішіне жаңа жазбалары бар сөздік беріңіз: бар кілттің мәні өзгереді, жоқ кілт қосылады.

8-тапсырма. Сөздіктер тізімі

Студенттер тізімінен ұпайы 80-ден кем емес студенттердің аты мен ұпайын шығарыңыз, содан кейін олардың санын шығарыңыз.

Кіріс деректері 
students = [
    {'name': 'Asan', 'score': 72},
    {'name': 'Dina', 'score': 90},
    {'name': 'Aru', 'score': 85},
    {'name': 'Eldos', 'score': 60}
]

for item in students: арқылы әр сөздікті алып, item['score'] >= 80 шартын тексеріңіз. Санауыш ретінде count = 0 қолданыңыз.
