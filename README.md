# Жиындар мен сөздіктер — статикалық оқу сайты

Қ. Жұбанов атындағы Ақтөбе өңірлік университеті · «Python-да қосымшалар құру» · 3-курс, 5-семестр, 7-апта · 21.10.2026

## Қалай ашады

1. `index.html`, `style.css`, `script.js` үш файлын **бір қалтаға** салыңыз (осы қалтаның өзінде тұр).
2. `index.html` файлын екі рет шертіп, браузерде ашыңыз. Сайт `file://` арқылы жұмыс істейді.

Сервер, интернет, тіркелу немесе сыртқы кітапхана қажет емес. Тек HTML5, CSS3 және таза JavaScript қолданылған.

## Не істей алады

- Практикалық сабақ: теория 15 минут (қайталау, жиындар, сөздіктер) және 8 практикалық тапсырма (35 минут).
- Зертханалық сабақ: 1–8 нұсқа таңдау (әр нұсқада 3 есеп; сайт нұсқаны кездейсоқ таратпайды), тапсыру тәртібі, бағалау критерийі.
- «Көшіріп алу» батырмасы кодты алмасу буферіне көшіреді. Браузер буферге рұқсат бермесе, қосалқы тәсіл қолданылады немесе мәтін белгіленеді.
- «Басып шығару» батырмасы браузердің өз баспа терезесін ашады.
- Таңдалған нұсқа тек осы браузерде (`localStorage`) сақталады.

## Не істей алмайды

Сайт Python кодын **орындамайды** және жауапты **тексермейді**. Студент кодты өз компьютерінде IDLE / VS Code / Python ортасында орындайды. Соңғы бағаны оқытушы қояды.

## Топ, кабинет, уақытты өзгерту

`script.js` файлының басындағы `CONFIG` нысанын түзетіңіз:

```js
var CONFIG = {
  group: '',            // мысалы: 'ИС-31'
  room: '',             // мысалы: '214'
  practiceMinutes: 50,
  labMinutes: 50,
  submitPlace: 'оқытушы көрсеткен орынға'
};
```

Бос мән қалдырсаңыз, бетте сызықша (`____`) көрінеді. Бөлімдердің минуттары (мысалы, «0–13 мин») `index.html` ішінде қарапайым мәтін: оны мәтіндік редакторда іздеп түзетуге болады.

## Файлдар

| Файл | Мазмұны |
|---|---|
| `index.html` | Бүкіл мазмұн: сабақ материалы, 8 нұсқа |
| `style.css` | Дизайн, адаптивтілік, баспа стилі |
| `script.js` | Қойындылар, тест, көшіру, нұсқа таңдау |

Оқытушының жауап кілті (`teacher-notes.md`) сайт қалтасының ішінде емес, бөлек беріледі. Оны студенттерге таратпаңыз.

## Оқытушыға арналған жауаптар беті

`admin-x7k2q9.html` — тест, практикалық тапсырмалар және зертханалық жұмыстың барлық нұсқаларының жауаптары. Сайттағы ешбір батырма немесе сілтеме оған апармайды: оны тек мекенжай жолына жазып (немесе файлды тікелей ашып) көруге болады. Атауын қаласаңыз өзгертіңіз.

**Маңызды:** студенттерге `admin-x7k2q9.html` файлынсыз қалтаны беріңіз немесе сайтты жариялағанда бұл файлды жүктемеңіз. Қалта ашық болса, студент файл атауын көріп қалуы мүмкін.
